4. กดปุ่มสีน้ำเงินมุมขวาบน การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้ใหม่ (New deployment)
  • คลิกรูปฟันเฟืองเลือกประเภท เว็บแอป (Web app)
  • ดำเนินการในฐานะ (Execute as): "ฉัน" (Me)
  • ผู้ที่มีสิทธิ์เข้าถึง (Who has access): "ทุกคน" (Anyone) **สำคัญมาก ต้องเลือกทุกคน**
  • กด ทำให้ใช้งานได้ (Deploy) แล้วอนุญาตสิทธิ์ จากนั้น คัดลอก URL เว็บแอป ที่ลงท้ายด้วย /exec นำมาวางในช่อง URL ในแอปนี้ แล้วกด บันทึก URL
